# The Elements of Style

William Strunk Jr.'s *The Elements of Style* (1918), packaged as a plugin for coding agents.

## Purpose

This plugin gives your agent an editing procedure built on Strunk's rules for drafts a person will read: messages, PR and ticket text, docs, commit message bodies, error and UI text.

This is a fork of [obra/the-elements-of-style](https://github.com/obra/the-elements-of-style). It keeps Strunk's text unchanged but rewrites the skill around it: a narrower trigger, a working procedure in `SKILL.md`, overrides where 1918 usage misleads modern technical prose, and the reference split so agents load only the part they need. [docs/fork-changes.md](docs/fork-changes.md) records what changed and why.

## What's Inside

- **Skill**: `writing-clearly-and-concisely` — the editing procedure, all 18 rules summarized with selected caveats, common cuts, modern-usage gotchas and examples (~1.9k tokens)
- **Reference** (`skills/writing-clearly-and-concisely/references/`): an abridged 1918 text, about 12,400 words (~15.6k tokens) across three files. Sections IV (form), VI (spelling) and VII (exercises) and the original introduction are omitted.

| File | Covers | Size |
|---|---|---|
| `usage-rules.md` | Elementary Rules of Usage: Rules 1–7, grammar and punctuation | ~2.8k tokens |
| `composition-rules.md` | Elementary Principles of Composition: Rules 8–18 | ~7.4k tokens |
| `misused-words.md` | Words and Expressions Commonly Misused: 65 entries, one heading each | ~5.4k tokens |

Token counts use the o200k tokenizer.

## Usage

Agents invoke `writing-clearly-and-concisely` when asked to tighten, copyedit or proofread a draft, and before finalizing prose a person will read. A routine edit needs only `SKILL.md`. The skill tells the agent to read a single rule or word entry from the reference when it needs Strunk's full explanation, and to hand long documents to a subagent.

## Installing

With the [skills CLI](https://github.com/vercel-labs/skills), for any harness that reads `~/.agents/skills` (Codex, omp) plus a symlink for Claude Code:

```
pnpm dlx skills add chrisvaillancourt/the-elements-of-style -g -s writing-clearly-and-concisely -a claude-code codex
pnpm dlx skills update writing-clearly-and-concisely -g   # later, to pick up changes
```

## Development

[everyharness](https://github.com/prime-radiant-inc/everyharness) generates every harness manifest, bootstrap hook, and install doc from one file: `everyharness.yaml`. Edit that file and the skill, then regenerate:

```
npx everyharness generate
```

Never edit a generated file by hand — `everyharness validate` fails on drift, and the next `generate` overwrites your change. Generated files carry a `GENERATED by everyharness` header, and `.everyharness/manifest.json` lists them all.
